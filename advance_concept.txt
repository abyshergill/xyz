Show reasoning
The cdn.tailwindcss.com script is a JIT compiler (JavaScript), not a static CSS file — you can't just save it as .css. Here are two approaches:

Approach 1 — Quick: Self-host the Play CDN script (still JIT, but no external dependency)
Step 1 — Download the script to your static folder:

curl -o static/js/tailwind.js https://cdn.tailwindcss.com
bash

Or manually download from https://cdn.tailwindcss.com and save it as static/js/tailwind.js.

Step 2 — Update base.html:

Replace this line:

<script src="https://cdn.tailwindcss.com"></script>
html

With:

<script src="{% static 'js/tailwind.js' %}"></script>
html

Make sure {% load static %} is at the top of base.html:

{% load static %}
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width-width, initial-scale=1.0">
  <title>{% block title %}YourTrolley{% endblock %}</title>
  <script src="{% static 'js/tailwind.js' %}"></script>
  <link rel="stylesheet" href="{% static 'css/main.css' %}">
</head>
html

This works but still compiles in the browser — slightly slower page load, and the file is ~400KB.

Approach 2 — Production-recommended: Build a static CSS file with Tailwind CLI
This generates a small, static .css file with only the classes you actually use — much faster and truly production-ready.

Step 1 — Install Tailwind CLI (one-time):

npm install -D tailwindcss
npx tailwindcss init
bash

Step 2 — Create tailwind.config.js in your project root:

module.exports = {
  content: [
    "./templates/**/*.html",
    "./stores/templates/**/*.html",
    "./orders/templates/**/*.html",
    "./accounts/templates/**/*.html",
    "./analytics/templates/**/*.html",
  ],
  theme: { extend: {} },
  plugins: [],
}
js

Step 3 — Create src/input.css:

@tailwind base;
@tailwind components;
@tailwind utilities;
css

Step 4 — Build the CSS:

npx tailwindcss -i ./src/input.css -o ./static/css/tailwind.css --minify
bash

Step 5 — Update base.html:

Replace:

<script src="https://cdn.tailwindcss.com"></script>
html

With:

<link rel="stylesheet" href="{% static 'css/tailwind.css' %}">
html

Step 6 — Add build step to docker-entrypoint.sh (before collectstatic):

echo "Building Tailwind CSS..."
npx tailwindcss -i ./src/input.css -o ./static/css/tailwind.css --minify
sh

Comparison
Approach 1 (Self-host JIT)	Approach 2 (Build static CSS)
File size	~400KB JS	~20-30KB CSS
Load speed	Slower (compiles in browser)	Faster (pre-compiled)
Requires Node.js	No	Yes (build time only)
Production-ready	Acceptable	Recommended
Flash of unstyled content	Possible	No



My recommendation: Use Approach 1 right now (quick, no Node.js needed). When you're ready to optimize for production, switch to Approach 2 — the built CSS file is ~15× smaller and loads instantly with no JavaScript compilation step.
